🧮 Basic Calculator in C++
📌 Project Description

This is a simple Basic Calculator developed using C++. It performs basic mathematical operations such as addition, subtraction, multiplication, division, and modulus.

The program uses a menu-driven approach and allows users to perform multiple calculations until they choose to exit.

✨ Features
Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Modulus (%)
Menu-driven interface
Input validation
Division by zero error handling
Repeat calculations without restarting the program
Exit option

🛠️ Technologies Used
Programming Language: C++
Compiler: GCC / MinGW
Editor: Visual Studio Code
▶️ How to Run the Program
1. Clone this repository
git clone https://github.com/Nidhi2600/Basic-Calculator-CPP.git

2. Open the project folder
cd Basic-Calculator-CPP

3. Compile the C++ program
g++ BasicCalculator.cpp -o calculator

5. Run the program
Windows:
calculator.exe

Linux / macOS:
./calculator
